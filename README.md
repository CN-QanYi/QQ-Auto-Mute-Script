# QQ 指定用户/群组 自动禁言脚本

这是一个基于 [NoneBot2](https://github.com/nonebot/nonebot2) 的 QQ 群自动禁言机器人。它采用**阶梯式连击惩罚机制**，专门针对特定用户群体的刷屏行为。

## 功能特性

*   **多群独立配置**：支持同时监控多个群聊，每个群可以设置**独立**的监控名单（黑名单）和触发阈值，互不干扰。
*   **连击惩罚机制**：
    *   每个群内的名单用户共享该群的“连击池”。
    *   累计发言达到设定阈值（如5句）后，**下一次**名单用户的发言将触发禁言。
    *   禁言时长呈阶梯式递增（1, 2, 3, 5, 7, 10... 分钟）。
*   **智能重置**：
    *   **打断重置**：如果该群有**非名单用户**发言，该群的连击计数立即归零。
    *   **超时重置**：如果该群名单用户超过 **3分钟**（可配）没有发言，该群的连击计数归零。
*   **定时禁言**：
    *   支持设置特定的时间段（如深夜、午休）。
    *   在这些时间段内，只要有**任意名单用户发言**，**所有名单用户**都将被禁言至该时段结束，防止打扰。
## 使用教程

### 1. 环境准备 (uv)
确保已安装 `uv` 工具。在文件夹目录打开终端：
```bash
# 创建虚拟环境 (可选，uv run 会自动处理，但手动创建更稳定)
uv venv

# 安装依赖
uv pip install -r requirements.txt
```

### 2. 配置管理 (WebUI)

本项目现已支持 **可视化 WebUI 配置面板**，无需修改代码即可管理群组、名单和策略。

**启动方式**：
启动机器人后，浏览器访问：
> http://127.0.0.1:8080/webui

(端口默认为 8080，可在 `.env` 文件中修改 `PORT`)

**WebUI 功能**：
*   **群组管理**：自动读取机器人所在的群列表。
*   **名单选择**：显示群成员列表（头像+昵称），勾选即可加入监控名单。
*   **搜索过滤**：支持通过昵称或 QQ 号搜索成员。
*   **策略配置**：
    *   **触发阈值**：设置多少次发言后触发禁言。
    *   **连击超时**：设置连击计数的重置时间（默认为各群独立的 180秒）。
    *   **定时禁言**：开关定时禁言功能，设置冷却时间。
    *   **时间段设置**：支持按 **星期** 设置不同的禁言时间段（如周末和工作日区分）。
*   **热重载**：保存配置后立即生效，无需重启机器人。

#### 离线群聊展示

当 QQ 机器人**未连接**时，WebUI 仍可正常展示已导入/已保存配置的群聊列表，方便用户**随时查看和管理历史配置**。

*   **自动回退**：`GET /api/groups` 接口在机器人离线时，自动从 `config.json` 中读取已配置的群号并展示。
*   **状态标识**：离线群聊在侧栏中显示 **「离线」** 徽章和降低透明度的视觉效果，顶部显示「机器人未连接」横幅提示。
*   **功能保留**：离线状态下仍可查看群配置详情、执行导入/导出操作。
*   **接口变更**：`GET /api/groups` 响应新增 `bot_connected` 字段（`boolean`），每个群对象新增 `offline` 字段（`boolean`）。

#### 导入-导出联动

执行「导入配置」操作后，**群聊列表** 和 **批量导出列表** 会**自动同步刷新**，确保两者数据始终一致。

*   **刷新机制**：导入成功后自动调用 `loadConfig()` + `loadGroups()` 刷新配置和群列表。
*   **批量导出同步**：批量导出 Modal 每次打开时从最新的 `config` 和 `groupSavedState` 动态读取，确保包含新导入的群配置。
*   **离线兼容**：离线状态下导入配置后，新导入的群同样会出现在侧栏中（标记为离线）。

#### 自动刷新

WebUI 顶部导航栏新增 **「自动刷新」** 开关：
*   **状态记忆**：自动记录开关状态，并在下次访问时自动恢复。
*   **定时更新**：开启后每 **10秒** 自动获取最新的群列表和成员列表。
*   **无感刷新**：采用静默加载模式，仅在后台更新数据，避免页面出现加载 Loading 遮罩，提升使用体验。


**配置文件**：
所有配置将保存在根目录下的 `config.json` 文件中。

### 3. 环境与依赖
> **提示**：如果已执行步骤 1 中的 `uv pip install -r requirements.txt`，以下依赖已自动安装，无需重复执行。

主要依赖项：
```bash
uv pip install nonebot2[fastapi] nonebot-adapter-onebot
```

### 4. .env 文件作用
项目根目录下的 `.env` 用于配置 NoneBot 的运行参数：

```env
HOST=127.0.0.1     # 监听地址
PORT=8080          # 监听端口
LOG_LEVEL=INFO     # 日志等级
COMMAND_START=["/"]
WEBUI_API_KEY=     # WebUI API 密钥（参见下方说明）
```

如果你修改了 `HOST` / `PORT`，请同步更新 OneBot 的反向 WebSocket 地址。

#### WebUI 认证说明 (`WEBUI_API_KEY`)

`WEBUI_API_KEY` 用于保护 WebUI 的 API 接口，对应代码中的 `API_KEY` 变量和 `verify_api_key` 函数。

- **空值**（默认）：认证功能禁用，任何人都可以访问 API
- **非空值**：所有 API 请求必须在 Header 中包含 `X-API-KEY: <你的密钥>`

> ⚠️ **安全警告**：如果你将 `HOST` 设置为非 `127.0.0.1`（如 `0.0.0.0`）或将服务暴露到互联网，**必须**设置一个强密钥。

**示例配置**：
```bash
# 在 .env 文件中
WEBUI_API_KEY="your-strong-secret-key-here"

# 或在 docker-compose.yml 中
environment:
  - WEBUI_API_KEY=your-strong-secret-key-here
```

**安全建议**：
- 使用至少 32 位的随机字符串作为密钥
- 不要将密钥提交到版本控制系统（使用 `.env` 并将其加入 `.gitignore`）
- 如果密钥泄露，立即更换并重启机器人

### 5. 连接机器人 (OneBot V11)
本程序需要配合 **NapCatQQ**, **LLOneBot**, **Lagrange** 等工具使用。
请在你的机器人工具中，添加一个 **反向 WebSocket** 连接：

*   **URL**: `ws://127.0.0.1:8080/onebot/v11/ws`
*   **Token**: (留空)

### 6. 启动
在终端中运行：
```bash
uv run bot.py
```

启动成功后，你会看到日志显示 `OneBot V11 | Bot ... connected`，表示连接成功。

## 注意事项
*   **机器人权限**：机器人QQ必须是群管理员或群主，否则无法禁言。
*   **报错处理**：如果报错，请检查终端日志。
*   **自定义惩罚**：在 `auto_mute.py` 中修改 `MUTE_LEVELS` 列表即可自定义惩罚阶梯。
