# QQ 指定用户/群组 自动禁言脚本

这是一个基于 [NoneBot2](https://github.com/nonebot/nonebot2) 的 QQ 群自动禁言机器人。它采用**阶梯式连击惩罚机制**，专门针对特定用户群体的刷屏行为。

## 功能特性

*   **多群独立配置**：支持同时监控多个群聊，每个群可以设置**独立**的监控名单（黑名单）和触发阈值，互不干扰。
*   **连击惩罚机制**：
    *   每个群内的名单用户共享该群的“连击池”。
    *   累计发言达到设定阈值（如5句）后，**下一次**名单用户的发言将触发禁言。
    *   禁言时长呈阶梯式递增（1, 2, 3, 5, 7, 10... 分钟）。
*   **智能重置**：
    *   **打断重置**：如果该群有**非名单用户**发言，该群的连击计数立即归零。
    *   **超时重置**：如果该群名单用户超过 **3分钟**（可配）没有发言，该群的连击计数归零。
*   **定时禁言**：
    *   支持设置特定的时间段（如深夜、午休）。
    *   在这些时间段内，只要有**任意名单用户发言**，**所有名单用户**都将被禁言至该时段结束，防止打扰。
## 使用教程

### 1. 环境准备 (uv)
确保已安装 `uv` 工具。在文件夹目录打开终端：
```bash
# 创建虚拟环境 (可选，uv run 会自动处理，但手动创建更稳定)
uv venv

# 安装依赖
uv pip install -r requirements.txt
```

### 2. 修改配置
打开 `src/plugins/auto_mute.py` 文件编辑顶部配置。
现在支持**为不同群设置不同的监控名单和触发频率**：

```python
GROUP_CONFIGS = {
    # === 群号 111222 ===
    111222: {
        # 该群的监控名单（刷屏的人）
        "target_users": [12345678, 87654321, 111111],
        # 几句开始触发禁言（默认5句以后，即第6句开始）
        "threshold": 5,
        # 定时禁言配置
        "scheduled_mute": {
            "enabled": True,       # 是否开启定时禁言
            "cooldown": 30,        # 冷却时间（秒）
            "ranges": [            # 时间段列表 (HH:MM)
                ("23:00", "07:00"), # 跨夜：晚上11点到早上7点
                ("12:00", "13:30")  # 午休
            ]
        }
    },

    # === 群号 333444 (另一个群) ===
    333444: {
        "target_users": [99999],
        "threshold": 3  # 这个群严格一点，3句就禁言
    }
}
```
*注意：只有在 `GROUP_CONFIGS` 里配置了的群，机器人才会生效。*

你还可以调整以下参数：

```python
# 连击判定的超时时间（秒）
COMBO_TIMEOUT = 180  # 3分钟

# 阶梯式禁言时长（分钟）
MUTE_LEVELS = [1, 2, 3, 5, 7, 10, 13, 17, 21]
```

### 3. .env 文件作用
项目根目录下的 `.env` 用于配置 NoneBot 的运行参数：

```
HOST=127.0.0.1     # 监听地址
PORT=8080          # 监听端口
LOG_LEVEL=INFO     # 日志等级
COMMAND_START=["/"]
```

如果你修改了 `HOST` / `PORT`，请同步更新 OneBot 的反向 WebSocket 地址。

### 4. 连接机器人 (OneBot V11)
本程序需要配合 **NapCatQQ**, **LLOneBot**, **Lagrange** 等工具使用。
请在你的机器人工具中，添加一个 **反向 WebSocket** 连接：

*   **URL**: `ws://127.0.0.1:8080/onebot/v11/ws`
*   **Token**: (留空)

### 5. 启动
在终端中运行：
```bash
uv run bot.py
```

启动成功后，你会看到日志显示 `OneBot V11 | Bot ... connected`，表示连接成功。

## 注意事项
*   **机器人权限**：机器人QQ必须是群管理员或群主，否则无法禁言。
*   **报错处理**：如果报错，请检查终端日志。
*   **自定义惩罚**：在 `auto_mute.py` 中修改 `MUTE_LEVELS` 列表即可自定义惩罚阶梯。
